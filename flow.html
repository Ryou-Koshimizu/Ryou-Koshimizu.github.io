FLOW

初回相談から公開まで、
安心のプロセス。

LUMENのWebサイト制作は、無料相談→提案→ご契約→制作・実装→公開・改善の5ステップで進みます。「何から始めればいいかわからない」という方も安心です。LP最短2週間・HP最短4週間での公開が可能です。

STEPS

5ステップで、集客するWebが完成。

01

無料相談・ヒアリング

約30〜60分

まず現状の課題を丁寧にヒアリングします。「今のWebサイトで問い合わせが来ない」「どのサービスを選べばいいかわからない」という段階から始めて大丈夫です。オンライン（Zoom/Meet）・LINE・訪問、お好きな方法で対応します。

聞くこと
現状のWebの状況・課題・目標・ターゲット・競合
方法
オンライン / LINE / 訪問 いずれでも対応
費用
完全無料。しつこい営業は一切しません
02

課題分析・ご提案

3〜5営業日

ヒアリング内容をもとに、現状のWeb診断レポートと改善提案書を作成します。「どのサービスが最も効果的か」「どのプランが最適か」を具体的にご提案。費用対効果を明確にしたうえでご検討いただけます。

  • 現状Webサイトの課題分析レポート
  • おすすめサービス・プランの提案
  • 競合サイト調査
  • スケジュール・費用の明確な提示
03

ご契約

ご検討はいつまでも

ご提案に納得いただけたら、「申込書兼契約書」を取り交わします。契約書の全文は、ご提案の段階でお渡しします。持ち帰ってじっくり読んでいただいて構いませんし、専門家に見せていただいても構いません。急かすことはしません。

  • 月額料金が発生するのはサイトの公開日から。制作期間中は費用がかかりません（第4条）
  • ドメイン・サーバーはお客様名義でご契約いただきます（第5条）
  • 12ヶ月の満了と料金の完済をもって、サイトの著作権をお客様に譲渡し、データ一式をお渡しします（第9条）
  • 12ヶ月未満で解約された場合、所有権の譲渡は行われず、解約事務手数料 55,000円（税込）を申し受けます（第10条。残りの月額料金を一括請求することはありません）。ただしドメイン・サーバーはお客様名義のため、解約後もサイトは表示され続けます
  • 検索順位・集客数・売上などの成果は保証しません。できない約束はしません（第13条）
04

制作・実装

LP 2〜3週／HP 4〜6週

合意内容をもとに制作を開始します。デザイン・コーディング・SEO設定・各種オプション実装まで一気通貫で対応。進捗はLINEまたはチャットで随時共有しますので、いつでも確認・ご意見をお伝えいただけます。

制作内容
  • ✓ デザイン制作
  • ✓ コーディング実装
  • ✓ SEO・Schema設定
  • ✓ スマホ対応
進め方
  • ✓ LINE/チャットで進捗共有
  • ✓ テスト公開で確認
  • ✓ 修正対応あり
  • ✓ LPなら最短2週間で公開
05

公開・効果測定・改善

公開後も継続

公開して終わりにしません。毎月のアクセス解析・ヒートマップ・問い合わせ数の推移をレポートし、改善提案を続けます。12ヶ月後にはサイトのすべてのデータをお渡しします。

  • 公開後のアクセス解析・ヒートマップ分析
  • 月次改善レポートと提案（Premium）
  • 修正・更新対応（プランに応じて月1〜4回）
  • 12ヶ月後に所有権を無償譲渡

FIRST MEETING

初回相談で何を話すか。

現状と課題

今のWebサイトにどんな問題があるか。問い合わせ数・アクセス数・競合との差など、現状をそのまま話していただければ大丈夫です。

目標・ゴール

「月に問い合わせを10件増やしたい」「新規客を○○から獲得したい」など、目標を共有します。具体的でなくても大丈夫です。

不安・疑問

「予算が心配」「IT系が苦手」「前の業者に失敗した」など、どんな不安でも遠慮なく話してください。その場で解決します。

💬 「まだ具体的な依頼内容が決まっていない」でも大丈夫。
現状の悩みを聞いて、「何から始めるべきか」をご一緒に整理するところから始めます。費用・サービスの説明は、ご希望があればお伝えします。押しつけは一切しません。

SCHEDULE

スケジュールの目安。

  1. 1週目
    ヒアリング・提案

    無料相談にて現状分析。3〜5営業日で提案書を作成します。

  2. 2〜3週目
    デザイン・制作

    デザイン・コーディングを進めながら進捗をLINEで共有します。

  3. 4週目
    確認・修正・公開

    テスト公開後に確認。ご意見をいただき修正のうえ本番公開します。

  4. 公開後〜12ヶ月
    運用・改善・譲渡

    毎月のレポート・改善で成果を継続。12ヶ月後に所有権譲渡。
